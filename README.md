# RonJuices - Juice Company Website

A modern, responsive one-page website for RonJuices, built with React.

## 🚀 Project Overview

RonJuices is a mockup juice company website featuring a clean, modern design with vibrant colors and smooth animations. The site showcases natural ingredients, energy-boosting products, and a professional brand presence.

## 🛠️ Tech Stack

- **React 18** - Modern React with hooks and functional components
- **Vite** - Fast build tool and development server
- **Tailwind CSS** - Utility-first CSS framework for styling
- **Flowbite** - Component library built on Tailwind CSS
- **GSAP** - Professional-grade animations and scroll triggers
- **React Router DOM** - Client-side routing (minimal usage for smooth scrolling)

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn package manager

### Installation

1. **Clone or download the project**

   ```bash
   cd ron-juices
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Start development server**

   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to `http://localhost:3000` to view the website

